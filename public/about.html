About Classic Games Arcade

Classic Games Arcade is a free collection of browser games. Every game runs instantly in your web browser, on a computer, tablet or phone, with no download, no install and no account.

What you can play

The arcade mixes two kinds of games:

  • Classics, rebuilt for modern screens: Tetris, Snake, 2048, Minesweeper, Pong, Breakout, Space Invaders, Memory Match, Simon, Ludo, Tic Tac Toe and more.
  • 3D games made with WebGL, from the Neon Rush and Prism Rush runners to Skyputt mini golf, Gearworks pinball, the Night Market management game and a voxel building world.

How it works

The games are written in plain HTML, CSS and JavaScript and load straight from this site. High scores and progress are stored in your own browser, so they stay on your device.

Open source

The full source code is on GitHub. Found a bug or have an idea for a game? Open an issue.
