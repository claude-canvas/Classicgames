Server Online

Termux MCP

A lightweight Model Context Protocol server running directly on an Android device via Termux. It exposes a small toolset that lets an AI assistant inspect and run commands inside a dedicated workspace on this phone, all gated behind Bearer token authentication.

📁

workspace_info

Reports the MCP workspace path, OS platform, CPU architecture, and the running Node.js version — a quick snapshot of the environment the assistant is operating in.

⚙️

exec

Runs a command with arguments and an optional working directory, returning exit code, stdout, and stderr. This is the core tool that lets the assistant act on the filesystem.

🔐

Bearer Auth

Every request to /mcp must carry a valid Bearer token, checked with a timing-safe comparison. Requests without it are rejected with 401 before anything else runs.

📡

HTTP Transport

Speaks MCP over plain HTTP, bound to 127.0.0.1 only. A separate unauthenticated /health endpoint reports basic liveness.

How a request flows
StepWhat happens
1. Request inClient sends a request to /mcp with an Authorization: Bearer <token> header
2. Auth checkToken is compared against the value stored in the token file using a timing-safe equality check
3. Tool callThe MCP handler routes the call to workspace_info or exec
4. ExecutionFor exec, the command is spawned as a child process (no shell interpolation) with a 30s timeout and a truncated output buffer
5. ResponseExit code, stdout, and stderr are packaged and streamed back to the client
