# Jade Pavilion — design & hand-off document

> Mahjong solitaire in 3D: hand-carved ivory-and-jade tiles stacked on a lacquered table in a lantern-lit tea
> pavilion. A UI-first game — every screen (title, layout picker, HUD, dock, settings, pause, results) is
> designed to feel premium. Built on the arcade's own `Space.js` (Projection 3D) — no Three.js, no build step.

This file is the single source of truth. If you are an AI (or human) picking this up, read it top to bottom,
then the files in the order of **File map**. Everything lives in `public/jade-pavilion/`; the only outside
file used is `../Space.js`, which is imported, never modified.

**Rule for this folder: do not edit any file outside `public/jade-pavilion/`.** (Home-page tile, sitemap,
thumbnails are deliberately not touched — that's the repo owner's call.)

## 1. The pitch

Clear the board by matching pairs of identical **free** tiles. A tile is free when nothing lies on top of it
and its left or right side is open. Tiles are real 3D objects: you can tilt and turn the stack to see what is
hidden, the light from paper lanterns glints off the jade, and every match lifts the pair into the air where
it dissolves into gold dust and blossom petals.

Unique in this arcade: there is no tile-matching/mahjong game, and none of the other games has a full
menu-driven UI shell (layout gallery with previews, themes, settings, statistics).

## 2. Rules

- 144-tile set: 3 suits (Dots 筒, Bamboo 條, Characters 萬) × 1–9 × 4 copies, 4 Winds 東南西北 × 4, 3 Dragons
  中 發 白 × 4, 4 Flowers 梅蘭菊竹 and 4 Seasons 春夏秋冬 (one each; **any flower matches any flower, any season
  any season**).
- **Free tile**: no tile on the layer above overlapping it, and no tile touching its left side *or* no tile
  touching its right side (same layer, vertically overlapping).
- Select one free tile, then a matching free tile → both removed. Wrong second tile → it becomes the selection.
- **Every deal is solvable**: generated by repeatedly removing a random pair of currently-free positions from
  the full layout and giving each removed pair the same tile kind (reverse construction). Playing that order
  forward always works.
- **No moves left** → modal offers Shuffle (re-deals the remaining tiles solvably) or Undo.

### Tools
| Tool | Key | Limit | Effect |
|---|---|---|---|
| Undo | U / Ctrl+Z | unlimited | restore the last pair (score penalty −20) |
| Hint | H | 3 per game | pulse a matching free pair (−50) |
| Shuffle | S | 2 per game | re-deal remaining tiles, still solvable (−100) |

### Scoring & stars
- Match +10, combo: matches within 4 s of each other multiply (+10 × combo, up to ×8).
- Finish bonus: + max(0, par·2 − seconds) × 2.
- ★ finish · ★★ finish with ≤ 1 hint and no shuffle · ★★★ finish under par time with no hint/shuffle.
- Save (`localStorage["jadepavilion.save"]`): per layout `{ best score, best time, stars, plays, wins }`,
  settings `{ theme, volume, highlightFree, showIndex }`.

### Layouts (`layouts.js`)
Each is a list of `[x, y, layer]` in tile units (x/y may be .5 for offset tiles), always an even count.

| Layout | Tiles | Difficulty | Par |
|---|---|---|---|
| Garden | ~48 | easy | 3:00 |
| Bridge | ~72 | easy-medium | 4:30 |
| Pagoda | ~96 | medium | 6:00 |
| Lotus | ~120 | medium-hard | 7:30 |
| Turtle (classic) | 144 | hard | 9:00 |

## 3. Presentation

### World
Z is up (Space.js). Tile = 1.0 (x) × 1.32 (y) × 0.72 (z), gap 0.05. Layout y grows toward the far side.
The board sits on a lacquered red-brown table with gold inlay; around it a dim pavilion: floor boards, red
pillars, hanging paper lanterns (emissive, swaying, they are the point lights), a moon window, drifting petals
and bokeh. Three **themes** recolour tile backs and the room: **Jade** (green backs, warm lanterns),
**Midnight** (indigo backs, cool moonlight), **Sakura** (rose backs, soft spring dusk).

### Tiles
Mesh per tile (rebuilt every frame, ~80 vertices): coloured back slab (theme), ivory top slab, chamfered top
edge, textured face. Face textures come from a 2048² canvas atlas (`tiles.js`) drawn at load with Noto Serif SC
(Google Fonts, subset to the ~30 glyphs needed via `&text=`), mip-mapped + anisotropic filtering.
States: hover (lift 0.05), selected (lift 0.16 + gold rim + gold glow), hint (jade pulse), blocked (dimmed if
"highlight free tiles" is on), matched (fly up together, flash, dissolve into particles), deal-in (drop from
above, staggered).

### Camera
Orbit around the board centre: drag to turn (yaw ±55°, pitch 28°–80°), wheel / pinch to zoom, double-click
or R to reset. Auto-fit distance from layout size and screen aspect. Clicks are picked by CPU ray–box tests.

### Materials (vertex format: pos = x,y,z,w · col = r,g,b,material)
| mat | name | notes |
|---|---|---|
| 0 | MATTE | room: lantern point lights + ambient + key light |
| 1 | GLOSS | tile slabs, lacquer: + strong specular, fresnel |
| 2 | FACE | tile face: col.rg = atlas uv, col.b = dim (+2 = hint), pos.w = gold glow |
| 3 | BG | full-screen backdrop gradient |
| 4 | SPRITE | additive glow quad, w = size + corner·100 |
| 5 | EMIT | lantern paper, candles, gold sparks |
| 6 | SHADOW | multiply-blended soft contact shadow under each tile, w = u·2 + v |
| 7 | ADD | additive geometry (selection rims) |

Draw order: BG → static opaque → dynamic opaque → shadows (multiply) → additive → bloom post (alpha = bloom
mask, as in tideglow).

## 4. UI (index.html — the star of this game)

- **Title**: seal stamp 翠亭, logo, tagline, Play, layout gallery (cards with an SVG top-down preview drawn
  from the layout data, difficulty pips, tile count, best time, stars), settings button.
- **HUD top bar** (glass): layout name · timer · score + combo chip · tiles left · available pairs.
- **Dock** (bottom): Undo, Hint (badge count), Shuffle (badge count), Pause — icons, labels, key hints,
  tooltips, disabled states.
- **Modals**: Pause, Settings (theme swatches, volume slider, toggles), No moves, Results (animated stars,
  stats grid, "new best" ribbon, Next layout / Replay / Menu).
- **Toasts** for blocked tiles, combos, hints. Fully responsive (phone portrait: compact bar, dock icons only).
- Keyboard: U undo, H hint, S shuffle, P/Esc pause, R reset camera, M mute.

## 5. Audio (audio.js, Web Audio only)
Tile clack (filtered noise + body tone) on select/deal, two-note pentatonic chime on match climbing with combo,
soft thud on mismatch, gong-like swell on win, quiet guzheng-style ambient plucks. Volume in settings.

## 6. File map
| File | Responsibility |
|---|---|
| `DESIGN.md` | this document |
| `index.html` | page, all CSS, UI markup; loads `main.js` |

| `post.js` | bloom/composite pipeline (alpha bloom mask) |
| `tiles.js` | tile set definition, matching rules, face atlas drawing |
| `layouts.js` | layout definitions, free-tile logic, solvable deal + shuffle generator |
| `scene.js` | static pavilion scene per theme |
| `audio.js` | sound |
| `main.js` | state machine, input/picking, animation, rendering, UI glue |

## 7. Debug URL parameters
`?layout=turtle` start directly · `?theme=sakura` · `?seed=5` · `?autoplay` (bot plays hints) ·
`?speed=4`. `window.__jade()` returns a state snapshot.

  Turtle 144 tiles), solvable deals + reshuffle, hint/undo/shuffle, combos, stars, saves, 3 themes, full UI shell.

  desktop 1440×900 and phone 390×844. 55–60 fps on Intel Iris Xe. Node check: 30/30 deals solvable per layout.
- Camera: play framing fits the board (`fitCamera`); the title uses a lower, wider shot offset to the right
  so the pavilion (moon window, lanterns) shows behind the text.

### Known rough edges / ideas
- Reshuffle can fail on rare end positions that are physically unsolvable (e.g. two tiles stacked); the UI
  then suggests Undo. A smarter fallback could undo automatically until a solvable state exists.
- Ideas: daily deal with a share code, more layouts (Dragon, Fortress), a tile-set picker (classic/modern),
  match-history replay, achievements panel.
